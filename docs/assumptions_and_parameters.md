# Перечень допущений, ограничений и конфигурируемых параметров

1. Фильтры сбоев датчиков скорости
- Максимальная валидная скорость: $v_{\max} = 75$ км/ч
- Порог рассогласования тележек: $\Delta v_{\text{thresh}} = 3.6$ км/ч
- Порог нулевой скорости: $v_{\text{zero}} \approx 1$ км/ч
2. Тормозной фильтр
- Порог ползания (остановки): $v_{\text{crawl}} = \frac{0.4 + 1.1 \cdot \frac{|u_{\text{cmd}}|}{15}}{3.6}$ м/с
- Предел замедления: $a_{\text{lim}} = \min(a_{\max}, 1.0 + 2.0 \cdot \frac{|u_{\text{cmd}}|}{15})$ м/с²
- Порог подавления шума: $0.4$ км/ч
3. Сглаживание (EMA)
- Коэффициент: $\alpha = \frac{2}{N + 1}$
4. Калибровка износа бандажей
- Диапазон $k_{\text{scale}}$: $[0.97, 1.03]$
- Прямые участки: $|\kappa| < 0.0001$ м⁻¹ ($R > 2000$ м)
- Минимальная длина участка: $L_{\min} = 70$ м
5. Компенсация кривизны
- Порог кривых: $R \leq 125$ м ($|\kappa| > 0.008$ м⁻¹)
- Коэффициент $\beta = 0.20$
- Базовая кривизна $\kappa_0 = 0.008$ м⁻¹
- Минимальный фактор: $0.85$

# Границы применимости

## Физические ограничения
- Максимальная скорость трамвая: $v_{\max} = 75$ км/ч
- Максимальное замедление при торможении: $a_{\max} \approx 3.0$ м/с²
- Минимальный радиус поворота трамвайных путей: $R_{\min} \approx 40$ м

## Рабочие диапазоны
- Скорость: $0 \leq v \leq 75$ км/ч
- Команда контроллера: $u_{\text{cmd}} \in [-15, 15]$ (15 ступеней торможения, 15 ступеней тяги)
- Коэффициент износа бандажей: $k_{\text{scale}} \in [0.97, 1.03]$

## Условия отказов
- При срыве данных с обоих тахометров модель не сможет работать
- При срыве одного тахометра: ошибка позиционирования возрастает, RMSE увеличивается до 5-20%
- Плохие погодные условия (дождь, снег, гололёд) могут увеличить RMSE из-за ухудшения сцепления
