# Описание ограничений решения и плана развития

## 1. Назначение и область применимости

Математическая модель предназначена для расчёта движения одиночного трамвайного вагона с двумя колёсными парами по заранее заданному графу пути `path_graph`.

Модель может использоваться и для других путей, но не автоматически: для каждого нового пути необходимо предоставить соответствующий `path_graph`. Без этого модель не может корректно определить топологию пути, последовательность участков, кривых, соединений и других параметров маршрута.

## 2. Ограничения решения

- Модель рассчитана на транспортное средство ровно с двумя колёсными парами.
- Не поддерживаются многовагонные, многосекционные и сочленённые трамваи.
- Модель не является универсальной без предварительной подготовки графа.

## 3. План развития

- Реализовать диагностику при отсутствии или неполноте `path_graph`.
- Покрыть тестами:
  - отсутствие `path_graph`;
  - неполный `path_graph`.
- Разработать генератор `path_graph`.
- Реализовать автоматическую проверку соответствия графа реальному пути.
- Расширить расчёт нагрузок и динамики.
- Сделать модель конфигурируемой через параметры.
